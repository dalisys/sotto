# Implementation map (Sotto0.2)

Root owns Models, AppModel, persistence, app entry, packaging and integration. CloudTranscriptionClient only calls OpenRouter; LocalTranscriptionService embeds CoreML Parakeet and connects to a loopback Whisper server. FloatingDictationPanel owns the nonactivating animated pill. Views show actual model, dictation and timing state. Keychain uses account openrouter-api-key, separate from the old generic-provider account. All cloud models are on OpenRouter; local Whisper/Parakeet are the user-authorized exception. Models do not download during dictation; explicit preparation is the only model-acquisition route. Optional editing is off by default and always uses OpenRouter, including after local ASR. Detailed behavior and current limitations are in README.md and LOCAL_BENCHMARK.md.
